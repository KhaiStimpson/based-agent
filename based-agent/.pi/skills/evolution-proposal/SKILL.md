# Evolution Proposal

## Quick start

Use this when a systemic improvement is suggested by failure attribution or repeated evidence. Produce a governed proposal rather than directly changing protected prompts, skills, topology, or policy.

## Workflow

- State the traced problem and primary failure category.
- Propose a bounded change with expected benefit, affected artifacts, and rollback plan.
- Check Endure, Excel, and Evolve gates in that order.
- Require human approval for broad-scope or protected changes before promotion.

## Example

After three validation misses, propose a skill update plus holdout case instead of silently rewriting routing policy.
