# Prospective Agenda

## Quick start

Use this when deferring work or tracking a future obligation. A useful reminder must include trigger, reason, required context, success criteria, and staleness threshold.

## Workflow

- Capture the deferred task in one concrete sentence.
- Record when to act, why it matters, files or commands needed, and blockers.
- Set priority and deadline or staleness threshold.
- Check pending obligations at session start and close them only with evidence.

## Example

Store a follow-up to rerun a flaky CI job with the PR number, failing workflow, retry command, and pass criteria.
