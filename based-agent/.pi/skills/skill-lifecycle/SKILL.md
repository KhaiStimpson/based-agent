# Skill Lifecycle

## Quick start

Use this to create, validate, promote, measure, or deprecate skills. Promote lessons only after evidence from repeated runs and keep skill entrypoints short.

## Workflow

- Identify the repeated pattern and evidence source.
- Draft or update SKILL.md with trigger-focused frontmatter, concise workflow, and concrete example.
- Move long material into one-level references or scripts.
- Validate on independent tasks before promotion and deprecate stale skills with provenance.

## Example

Promote a recurring validation playbook only after it succeeds on at least two independent tasks with recorded outcomes.
