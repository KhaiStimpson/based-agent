# Lifelong Memory

## Quick start

Use this when storing or retrieving durable project knowledge. Maintain typed memories with provenance; never treat raw chat logs as general memory.

## Workflow

- Retrieve structural and declarative memory first when starting unfamiliar work.
- Add only evidenced facts, decisions, lessons, and obligations.
- Include type, scope, status, confidence, salience, provenance, and validation timestamp.
- Deprecate or contradict stale memory instead of silently deleting it.

## Example

Record a validated build command with the exact repo path, command, date, and evidence after it succeeds.
